# Design Tokens

Tokens are the single source of truth. In Tailwind v4 they live in CSS inside
`@theme`, and every token becomes a utility automatically
(`--color-accent` → `bg-accent` / `text-accent` / `border-accent`). Because the
utilities reference the CSS variables, **overriding a variable re-themes the
whole system** — which is exactly how the dark theme below is implemented.

## Color

<div style={{ display: "flex", flexWrap: "wrap", gap: 16, marginTop: 16 }}>
  {[
    ["canvas", "#FBFBFB", "page background"],
    ["surface", "#FFFFFF", "raised surfaces"],
    ["ink", "#1A1A1A", "primary text"],
    ["ink-muted", "#666666", "secondary text"],
    ["ink-subtle", "#8A8A8A", "placeholders"],
    ["rule", "#E8E6E3", "hairline borders"],
    ["accent", "#0F766E", "links, primary actions"],
    ["accent-ink", "#0B5D56", "accent hover"],
    ["danger", "#B42318", "errors"],
  ].map(([name, value, note]) => (
    <div key={name} style={{ width: 116 }}>
      <div
        style={{
          height: 56,
          borderRadius: 8,
          border: "1px solid var(--color-rule)",
          background: `var(--color-${name})`,
        }}
      />
      <div style={{ marginTop: 6, fontSize: 12, fontWeight: 600 }}>{name}</div>
      <div style={{ fontSize: 11, fontFamily: "monospace", opacity: 0.6 }}>{value}</div>
      <div style={{ fontSize: 11, opacity: 0.6 }}>{note}</div>
    </div>
  ))}
</div>

> Switch the **Theme** toolbar control to **Dark** and the swatches above remap
> live — the token values change, the markup doesn't.

## Radius, type & motion

| Token | Value | Utility |
| --- | --- | --- |
| `--radius-control` | `8px` | `rounded-control` |
| `--radius-card` | `12px` | `rounded-card` |
| `--font-display` | Urbanist | `font-display` |
| `--font-sans` | Inter | `font-sans` |
| `--ease-out-soft` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | transitions |

## Re-theming in a consumer app

```css
/* your app's global stylesheet, loaded after the library's styles.css */
:root {
  --color-accent: #7c3aed;   /* swap teal for violet, everywhere */
  --radius-control: 12px;
}
```
